Overview:
    This project contains an AI agent built to analyze legacy legal templates and convert them
    to the Pine syntax.
Running:
    Requirements:
        - OpenAI api key
    Directions:
        - Add the OpenAI api key to a .env file, OPENAI_API_KEY="your key"
        - Install the necessary requirements using, pip install -r requirements.txt, a venv is recommended
        - run the agent from main.py, python3 main.py
